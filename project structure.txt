## Architecture Overview

This is a comprehensive calorie tracking application built with Flutter using the GetX state management pattern. The app follows a clean architecture with separation of concerns:

1. __State Management__: Uses GetX for reactive state management, dependency injection, and routing
2. __Database__: SQLite via sqflite package for local data persistence
3. __AI Integration__: OpenAI API for food image recognition and chatbot functionality
4. __Camera__: Flutter camera package for food photography
5. __In-App Purchases__: For premium features

## Core Functionality

### 1. User Onboarding & Authentication

- Onboarding flow with carousel introduction screens
- User profile setup with personal details (age, height, weight, gender)
- Goal setting with automatic calculation using BMR formulas

### 2. Calorie Tracking Methods

__Image Recognition:__

- Camera integration for capturing food photos
- Image cropping before processing
- OpenAI GPT-4 integration for calorie estimation
- Nutritional data extraction using regex parsing

__Manual Entry:__

- Predefined food database organized by meal type (breakfast, lunch, snacks, dinner)
- Search functionality for quick food lookup
- Nutritional values stored for hundreds of food items

### 3. Data Management

__Local Database:__

- SQLite database with multiple tables:

  - Calorie tracking by date
  - Daily calorie history with images
  - Chat conversation history
  - Food consumption records

__Data Models:__

- SqlCalorieModel: Daily calorie summaries
- CalorieHistoryModel: Individual food entries
- Chat models for AI conversations

### 4. Analytics & Visualization

- Weekly, monthly, and yearly calorie consumption charts
- Syncfusion charts for data visualization
- Weight tracking with goal management
- Progress monitoring toward calorie targets

### 5. AI Features

__Food Recognition:__

- Image analysis using OpenAI GPT-4
- Nutritional value extraction from food images
- Multi-language support in AI responses

__Chat Assistant:__

- Real-time chat with nutrition expert AI
- Speech-to-text input capability
- Conversation history storage
- Image-based queries for food analysis

### 6. Premium Features

- In-app purchases for unlocking unlimited scans
- Subscription tiers (weekly, monthly, yearly)
- Purchase restoration functionality

### 7. User Experience

__UI/UX Features:__

- Dark/light theme support
- Multi-language support (15+ languages)
- Responsive design for various screen sizes
- Intuitive navigation with bottom tabs

__Customization:__

- Personalized calorie goals based on BMR calculations
- Adjustable macronutrient targets (protein, carbs, fats)
- Theme switching capability

## Technical Implementation Details

### Key Components:

1. __MainController__: Global state management for app settings
2. __DatabaseHelper__: SQLite database operations abstraction
3. __OpenAiCalling__: OpenAI API integration for image analysis
4. __GetX Routing__: Named route management with bindings
5. __ThemeService__: Dark/light mode implementation
6. __Localization__: Multi-language support with translation files

### Data Flow:

1. User captures/selects food image
2. Image sent to OpenAI for analysis
3. Response parsed for nutritional values
4. Data stored in SQLite database
5. UI updates reactively through GetX controllers
6. Analytics charts generated from database queries

### Premium Implementation:

- Scan limit tracking for free users
- In-app purchase integration with platform-specific IDs
- Purchase validation and date tracking
- Feature gating for premium functionality

The application demonstrates a well-structured Flutter architecture with proper separation of concerns, reactive programming patterns, and integration with external APIs for enhanced functionality.
